# Lucio Magi

Portfolio oficial de Lucio Magi.

Este sitio presenta su perfil como DJ y productor, su propuesta artística, sus lanzamientos, sus redes sociales y sus links oficiales en un solo lugar.

La web fue pensada como una experiencia visual sobria y nocturna, con una estética alineada a su identidad musical y una navegación simple para descubrir su contenido, escuchar sus sets y acceder rápidamente a sus plataformas.
